# Optional resource-rule and exogenous-noise controls

Protocol 2.3.0 adds two independently selectable controls. Both default to false. They do not change harvest limits, population incentives, resource equations or treaty enforcement. Old pilot artifacts retain their original protocol/source metadata.

`config.includeNumericRules=true` appends the numerical resource rules to the existing prompt: visible-resource capacity, regeneration and collapse threshold; governance adjustment; scarcity allocation; stochastic depletion and shock; irreversibility; and the absence of a treaty resource fine. It exposes parameters for visible resource IDs only, never hidden stock amounts or hidden resource definitions. This is resource-rule grounding, not a complete population-utility specification or evidence of model comprehension. The original prompt remains unchanged when this flag is absent.

`config.useIndependentRandomStreams=true` uses deterministically keyed draws for resource-estimate noise, observed-species noise, physical harvest noise and environmental shocks. Keys contain the world seed, namespace, world step and relevant species/resource IDs. Adding a treaty ID, changing speech or skipping an unrelated resource therefore cannot advance another resource's shock sequence. Each keyed stream uses a source-versioned 32-bit Mulberry32 generator with FNV-1a label derivation; this is reproducible pseudorandom stream isolation, not a claim of cryptographic randomness or a proof of statistical independence. World generation, administrative IDs and language randomness retain their legacy stream.

The shared runner supplies the exact environmental seed in `config.rngSeed`. Direct lower-level use of keyed draws requires that explicit seed. Direct resource updates also require an explicit nonnegative world step in keyed mode; omitting it fails instead of silently reusing the same noise at every step. Legacy calls can continue to omit it.

Regression controls demonstrate that treaty creation leaves physical resource trajectories and resource observation noise unchanged with keyed streams while shifting the legacy shared stream. Reordering resources does not change keyed outcomes. The existing 20 archived fixed-policy trajectory hashes remain the required default-compatibility check. Neither flag makes external model inference deterministic.

Before an institution/visibility study, require a separately frozen protocol, transparent decision reference, manipulation/comprehension checks, held-out worlds, preserved failures and a valid uncertainty/attrition analysis. The existing `useEpistemicOrders` switch changes access and acting cadence as well as information, so it cannot identify a pure visibility effect. Existing treaty records do not establish independent consent or binding resource enforcement. The optional controls alone are not a completed causal study.
